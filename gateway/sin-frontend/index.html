El backend está funcionando

Este es el API Gateway de la Veterinaria San Marcos. La API está en /api/v1 y su documentación en /swagger-ui.html.

En desarrollo, el sitio se abre con npm run dev en la carpeta del frontend (http://localhost:3000).

En el servidor, el gateway sirve el frontend compilado: se indica su carpeta dist en la variable SITIO_WEB del archivo .env.
